# Fabric 官方脚手架 CLI (`create-fabric-plugin`)

Fabric 内置了一等脚手架工具 `create-fabric-plugin`，用于快速生成符合 DSH 与 Fabric 规范的完整插件项目骨架。

---

## 1. 快速开始

```sh
# 使用 npx 快速创建
npx create-fabric-plugin my-cool-plugin

# 或指定相对/绝对路径
npx create-fabric-plugin ./plugins/my-cool-plugin
```

---

## 2. 生成的工程目录结构

脚手架自动生成具备 Node 宿主半部、浏览器客户端半部、tsdown 构建预设与 DSH patch 的标准工程：

```
my-cool-plugin/
├── package.json          # 声明 dsh.bundle.patch 与 dsh.client.inject
├── tsdown.config.ts      # 使用 fabricPlugin() 预设
├── tsconfig.json         # 严格 TypeScript 配置
├── cordis.patch.yml      # DSH profile bundle 注入补丁
├── README.md             # 安装与调试指南
└── src/
    ├── index.ts          # Node 宿主入口（挂载后端路由与持久化）
    └── client/
        └── index.ts      # 浏览器客户端入口（注册工作台页面、Mod卡片）
```

---

## 3. 模板代码核心规范

### 3.1 `package.json`
脚手架预配置了正确的 DSH 客户端注入关系与 peer 依赖：

```json
{
  "name": "my-cool-plugin",
  "version": "0.1.0",
  "private": true,
  "type": "module",
  "main": "lib/index.js",
  "exports": {
    ".": "./lib/index.js",
    "./client": "./lib/client.js"
  },
  "dsh": {
    "bundle": { "patch": "./cordis.patch.yml" },
    "client": {
      "inject": [
        "@deepseek-ai/dsh-client-runtime",
        "@deepseek-ai/dsh-client-ui-primitives",
        "@deepseek-ai/dsh-client-ui-slots",
        "@dsh-do/fabric"
      ],
      "platform": "web"
    }
  },
  "peerDependencies": {
    "@dsh-do/fabric": "^0.4.0",
    "react": "^18.2.0"
  }
}
```

### 3.2 客户端入口（`src/client/index.ts`）
脚手架自动导出 `inject = ['fabric'] as const`，确保 Cordis 启动时等待 Fabric 服务：

```tsx
import type { ClientContext } from '@deepseek-ai/dsh-client-runtime/client'
import type { FabricPageProps } from '@dsh-do/fabric/client'
import { Page, PageHeader } from '@dsh-do/fabric/ui'

export const inject = ['fabric'] as const

function HomePage(_props: FabricPageProps) {
  return (
    <Page>
      <PageHeader title="My Cool Plugin" description="Generated by create-fabric-plugin." />
    </Page>
  )
}

export function apply(ctx: ClientContext): void {
  ctx.fabric.register({
    kind: 'mod',
    id: 'my-cool-plugin',
    name: 'My Cool Plugin',
    version: '0.1.0',
  })
  ctx.fabric.register({
    kind: 'page',
    id: 'my-cool-plugin',
    label: 'My Cool Plugin',
    pluginId: 'my-cool-plugin',
    component: HomePage,
  })
}
```

### 3.3 构建配置（`tsdown.config.ts`）
直接消费 `@dsh-do/fabric/build` 提供的 `fabricPlugin` 预设：

```ts
import { defineConfig } from 'tsdown'
import { fabricPlugin } from '@dsh-do/fabric/build'

export default defineConfig(fabricPlugin({
  id: 'my-cool-plugin',
}))
```

## 4. 插件调试与本地安装

```sh
cd my-cool-plugin
pnpm install
pnpm build

# 打包成本地 tarball 并安装至 DSH Web profile
pnpm pack --pack-destination .
dsh plugin --profile web add "$(pwd)/my-cool-plugin-0.1.0.tgz"
dsh --profile web
```

---

## 5. 编程式 API

脚手架能力同样暴露在 `fabric/create` 入口中，可供工具链与自动化脚本调用：

```ts
import { scaffoldPlugin } from '@dsh-do/fabric/create'

const files = await scaffoldPlugin({
  name: 'custom-widget',
  directory: '/path/to/project',
})
console.log('已生成文件:', files)
```
